# Self Health Tracking App

A PHP-based web application for recording personal travel history and body temperature during the COVID-19 pandemic. The application includes user and admin dashboards to support personal record management and user activity monitoring.

Built using PHP and JavaScript, with Bootstrap 5 and custom CSS for the user interface.

## Key Features

### User Features

- **Authentication** – Register, login, and logout.
- **User Dashboard** – View personal activity summaries.
- **Health & Travel Records** – Record travel locations, dates, times, and body temperature.
- **Record Management** – View, sort, print, and delete personal travel records.
- **Profile Management** – Update personal information.

### Admin Features

- **Admin Authentication** – Secure login for administrators.
- **Statistics Dashboard** – View user activity statistics.
- **User Management** – View, edit, delete, and print user lists.
- **Travel History Management** – View, edit, and delete users' travel records.
