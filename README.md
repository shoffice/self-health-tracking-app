<h1>Peduli Diri App dengan Admin Panel</h1>
<p>Aplikasi web sederhana untuk mencatat riwayat perjalanan pribadi dan suhu tubuh selama pandemi. Dibangun menggunakan bahasa PHP dan JavaScript. Tampilan menggunakan Bootstrap 5 dengan beberapa kustomisasi CSS untuk penyesuaian desain. Aplikasi ini dilengkapi dengan dashboard admin untuk melihat statistik aktivitas non-admin dan manajemen data pengguna.</p>
